# ONDO Office

문서·일정·할 일을 관리하는 한국어 웹 업무 대시보드입니다.

운영 주소: https://ondo-ai-office.vercel.app

## 주요 기능

- 오늘 할 일, 일정, 최근 문서, 업무 달성률 대시보드
- 할 일 추가·수정·삭제·완료 처리, 우선순위와 마감일, 상태별 필터
- 월간 캘린더와 날짜별 일정 등록·수정·삭제
- 문서 작성·수정·삭제·분류, 제목·본문 통합 검색
- 저장된 업무를 계산해 보여 주는 기본 업무 브리핑
- JSON 백업 내보내기·가져오기, 모바일 화면 지원

AI 채팅, Codex 연결, 외부 AI API 호출은 포함하지 않습니다. 기본 업무 브리핑도 AI 없이 브라우저에서 계산합니다.

## 접속 및 데이터 저장

Vercel 도메인에서 바로 사용합니다. PC에서 별도 프로그램을 실행할 필요가 없습니다.

업무 데이터는 접속한 브라우저의 localStorage에 저장됩니다. 로그인, 서버 데이터베이스, 기기 간 자동 동기화는 아직 포함하지 않습니다. 같은 기기에서도 브라우저나 사이트 주소가 다르면 저장소가 다릅니다. 브라우저 데이터를 삭제하기 전에 JSON 백업을 내려받으세요.

처음 표시되는 업무·일정·문서는 사용법을 위한 예시이며 자유롭게 수정할 수 있습니다.

### 기존 PC 버전 데이터 가져오기

기존 PC 업무 데이터는 로컬의 무시된 `.local/office.json`에 보존돼 있습니다. 웹사이트의 **백업 가져오기**, 또는 **워크스페이스 정보 → 백업 가져오기**에서 해당 JSON 파일을 선택하세요. 현재 브라우저 데이터가 교체되므로 먼저 백업을 내려받는 것이 좋습니다. 가져온 파일은 브라우저에서 처리하며 서버에 업로드하지 않습니다.

## 개발 및 검증

Node.js 22 이상. 별도 런타임 패키지 설치가 필요하지 않습니다.

```sh
npm run dev
npm test
npm run build
```

개발 미리보기는 http://localhost:3000 입니다. 실제 서비스는 위 Vercel 주소에서 이용합니다.
