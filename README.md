## 작업 및 동기화

이 폴더는 위 GitHub 저장소의 로컬 작업 폴더입니다. 완료한 작업은 필요한 검증을 거쳐 커밋하고 푸시합니다. 작업 규칙은 `AGENTS.md`에 기록되어 있습니다.

## Vercel 배포

현재 앱 소스와 Vercel 프로젝트 연결은 아직 준비되지 않았습니다.

배포할 앱을 추가한 뒤 Vercel에서 이 GitHub 저장소를 가져오고, 앱에 맞는 프레임워크·루트 폴더·빌드 설정과 환경 변수를 지정합니다. Production Branch를 `main`으로 설정하면 해당 브랜치에 푸시한 변경 사항이 자동 배포됩니다.

공식 문서: https://vercel.com/docs/git/vercel-for-github
